# Тексты бота по умолчанию

**Статус:** ✅ утверждён

Тексты, которые оператор видит из коробки и может переписать в админке ([решение 0018](decisions/0018-languages.md)). Структура экранов — [03-screens.md](03-screens.md).

## Соглашения
- **Ключ** — идентификатор текста; по нему текст хранится для каждого языка.
- **`{переменная}`** — подставляется магазином. Оператор может переставлять и убирать переменные, но не придумывать новые.
- **Даты** (`{end_date}` и другие с `_date`/`_at`) выводятся через сущность date_time.
- **Числа с единицами** (`{days_text}`, `{period}`) подставляются с правильным множественным числом.
- **Rich-экраны** (З3, З4, С2): оператор правит тексты полей, структуру собирает магазин.

## Общие переменные
| Переменная | Значение |
|---|---|
| `{brand_name}` | Название бренда |
| `{welcome_text}` | Приветственный текст бренда (чек-лист, 1.11) |
| `{support_contact}` | Контакт поддержки |
| `{subscription_name}` | Название подписки |
| `{subscription_link}` | Ссылка на подписку |
| `{tariff_name}`, `{period}`, `{price}` | Тариф, срок, цена |
| `{end_date}` | Дата окончания подписки |

## З1. Главное меню
`menu.header.new` — клиент без подписок
```
Добро пожаловать в {brand_name}!

```

```
Быстрый и надёжный VPN. Подключение занимает пару минут.
```
`menu.header.subscriptions` — есть подписки
```
{brand_name}

{subscriptions_summary}
```

```
С возвращением! Мы переехали в новый бот, и ваши подписки уже здесь. Ссылки остались прежними — ничего перенастраивать не нужно.

{subscriptions_summary}
```
Строка сводки `{subscriptions_summary}` — по одной на подписку:

| Ключ | Текст |
|---|---|
| `summary.active` | {subscription_name} — до {end_date} |
| `summary.expired` | {subscription_name} — истекла {end_date} |
| `summary.disabled` | {subscription_name} — отключена |

`menu.stale_data` — панель недоступна (4.12)
```
Данные могут быть неактуальны — обновим, как только сервер ответит.
```

## События

### С1. Подписка готова
`event.subscription_ready`
```
Подписка готова!

Ваша ссылка:
{subscription_link}

Добавьте её в приложение — инструкция по кнопке ниже.
```

### С2. Инструкция по подключению — rich
Заголовки, названия платформ и приложений, шаги и тексты кнопок берутся из конфига Subscription Page на языке клиента ([решение 0019](decisions/0019-subpage-guide.md)). Свои тексты магазина:

| Ключ | Текст |
|---|---|
| `btn.other_apps` | Другие приложения |
| `btn.open_in_browser` | Открыть в браузере |

`guide.unavailable` — конфиг ещё ни разу не был получен
```
Инструкция временно недоступна. Скопируйте ссылку и откройте её в браузере — там есть подробная инструкция.
```

### С3. Триал активирован
`event.trial_activated`
```
Пробный период на {trial_period} активирован!

Ваша ссылка:
{subscription_link}

Подписка действует до {end_date}.
```

### С4. Оплата получена, подписка создаётся
`event.payment_processing`
```
Оплата получена. Создаём подписку — это займёт немного времени. Мы пришлём сообщение, как только всё будет готово.
```

### С5. Оплата не прошла
`event.payment_failed`
```
Платёж не прошёл. Попробуйте ещё раз — например, с другой картой.
```

### С6. Подписка продлена
`event.renewed`
```
Подписка «{subscription_name}» продлена до {end_date}. Спасибо, что остаётесь с нами!
```

### С7. Напоминание
`reminder.before`
```
Подписка «{subscription_name}» заканчивается {end_date}. Продлите заранее, чтобы VPN не отключился.
```
`reminder.before.archived` — добавляется, если тариф в архиве
```
Ваш тариф больше не продаётся: продлить его можно только до окончания подписки, потом нужно будет выбрать новый.
```
`reminder.after`
```
Подписка «{subscription_name}» закончилась {end_date}. Продлите её — ссылка и настройки останутся прежними.
```

### С8. Подписка истекла
`event.expired`
```
Подписка «{subscription_name}» истекла. Продлите её, чтобы снова пользоваться VPN.
```

### С9. Триал закончился
`event.trial_ended`
```
Пробный период закончился. Понравилось? Оформите подписку — ссылка и настроенное приложение останутся прежними.
```

### С10. Добавлены дни
`event.days_added`
```
К подписке «{subscription_name}» добавлено {days_text}. Теперь она действует до {end_date}.
```

### С11. Возврат выполнен
`event.refunded`
```
Возврат по платежу от {payment_date} выполнен. Подписка «{subscription_name}» теперь действует до {end_date}.
```
`event.refunded.ended` — при полном возврате
```
Возврат по платежу от {payment_date} выполнен. Подписка «{subscription_name}» завершена.
```

### С12. Платёж разобран командой
| Ключ | Текст |
|---|---|
| `event.payment_resolved.created` | Мы разобрались с вашим платежом: подписка создана. |
| `event.payment_resolved.renewed` | Мы разобрались с вашим платежом: подписка «{subscription_name}» продлена до {end_date}. |
| `event.payment_resolved.refunded` | Мы разобрались с вашим платежом: деньги возвращены. |
