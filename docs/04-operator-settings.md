# 4. Настройки оператора

**Статус:** ✅ утверждён

Всё, что оператор может настроить, где это делается и что стоит по умолчанию. 

## Правила
- **`.env`** — только секреты и инфраструктура, без которых магазин не запустится (1.1).
- **Админка** — всё остальное. Пункты с пометкой «чек-лист» показываются в чек-листе первичной настройки (1.7).
- **Изменения в админке применяются сразу,** без перезапуска.
- **Секреты, которые вводятся в админке** (ключи платёжных провайдеров), хранятся в базе в зашифрованном виде; ключ шифрования лежит в `.env`. Так сохраняется обещание «платёжки настраиваются в админке» и не страдает безопасность.

## `.env`
| Параметр | Назначение | Обязателен |
|---|---|---|
| Токен бота | Доступ к Telegram Bot API | да |
| Адрес API панели | Подключение к Remnawave | да |
| Токен API панели | Подключение к Remnawave | да |
| Подключение к базе данных | Хранение данных магазина | да |
| Telegram ID первого владельца | Первый вход в админку (1.2) | да |
| Публичный адрес магазина (HTTPS) | Вебхуки провайдеров и панели, страница-переходник, вход в админку | да |
| Ключ шифрования | Шифрование секретов, введённых в админке | да |

## Уведомления команде
В MVP уведомления команде приходят владельцам в Telegram через бот: «Требуют внимания», неизвестный платёж, недоступность панели, двойная оплата (3.11). Отдельных настроек уведомлений в MVP нет.
