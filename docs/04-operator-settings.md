# 4. Настройки оператора

**Статус:** ⬜ не начат

Всё, что оператор может настроить, и где именно это делается.

## Правило размещения настроек
- **`.env`** — только секреты и инфраструктура: токены, ключи, адреса сервисов.
- **Мастер первого запуска** — минимум, без которого магазин не заработает.
- **Веб-админка** — всё остальное, с применением без перезапуска.

## Шаблон настройки
```
### Название
- **Где:** .env / мастер / админка
- **Что меняет:**
- **Значение по умолчанию:**
- **Применяется:** сразу / после перезапуска
```
