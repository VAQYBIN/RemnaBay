# 6. Объём версий и критерии приёмки

**Статус:** 🟡 нарезка собрана, критерии приёмки не начаты

## Версии
([решение 0015](decisions/0015-mvp-definition.md))
- **MVP** — минимум, с которым автор переводит на проект свой действующий магазин.
- **v1** — минимум для публичного релиза, когда проект не стыдно показать сообществу.
- **Потом** — всё остальное; идеи живут в [backlog.md](backlog.md).

## Данные с первого дня
Модель из [01-domain.md](01-domain.md) реализуется в MVP целиком, даже если функции поверх неё отложены. Откладываются экраны и действия, но не данные. Пометка «данные — MVP, функция — v1» означает: MVP хранит и поддерживает эти данные, а интерфейс появится в v1.

## Нарезка

### Ядро и надёжность
| Фича | Этап | Почему |
|---|---|---|
| Ядро, бот, базовая веб-админка | MVP | Без этого нет продукта |
| Вход через Telegram, первый владелец из `.env` | MVP | Иначе в админку не попасть |
| Чек-лист первичной настройки | MVP | Автор настраивает с нуля |
| Режим «магазин скоро откроется» | MVP | Часть первичной настройки |
| Журнал действий | MVP | Основа обещания надёжности |
| Вебхуки панели с проверкой подписи, сверка, повтор операций | MVP | «Деньги пришли — услуга будет» |
| Разбор «оплачен, не применён» | MVP | Там же |

### Клиент
| Фича | Этап | Почему |
|---|---|---|
| Первая покупка, продление | MVP | Ядро магазина |
| Тариф «срок + безлимит» | MVP | Модель автора |
| Тарифы с квотой и пакетами, докупка пакета | v1 | Автору не нужны, сообществу нужны |
| Архивация тарифа | MVP | Скрыть тариф из продажи нужно сразу |
| Закрытие тарифа, тариф-преемник | v1 | Нужно при смене линейки, а не при переезде |
| Триал: параметры, один на клиента | MVP | У автора есть триал |
| Реестр устройств | данные — MVP | Иначе проверке триала не на что опереться |
| Отзыв триала по устройству, чёрные списки | v1 | У автора злоупотреблений нет, у сообщества есть |
| Подписка на канал для триала | потом | Маркетинг, а не защита |
| Точка расширения проверок триала | потом | |
| Управление устройствами | MVP | Лимит устройств используют почти все |
| Ограничение числа удалений устройств | потом | |
| Напоминания, планировщик | MVP | Главный механизм удержания |
| Помощь с подключением | v1 | Улучшение |
| Уведомления о трафике | v1 | Вместе с тарифами с трафиком |
| Кнопка «Поддержка» | MVP | Необходимо |
| Несколько подписок, переименование | данные — MVP, функция — v1 | |
| Смена тарифа с перерасчётом | данные — MVP, функция — v1 | Отрезки со стоимостью копятся с первого платежа |
| Бонусный счёт, смешанная оплата | v1 | Нужен смене тарифа и наградам бонусами |
| Промокоды: дни, скидка в процентах | MVP | Используются автором |
| Промокоды: фиксированная скидка, бонусы | v1 | Бонусы — вместе с бонусным счётом |
| Реферальные ссылки и связи | данные — MVP | Новые связи записываются, старые переносятся при миграции |
| Реферальные награды, приветственный бонус | v1 | Вместе с бонусным счётом; награды за оплаты периода MVP начисляются задним числом при запуске v1 |

### Миграция
| Фича | Этап | Почему |
|---|---|---|
| Усыновление по Telegram ID | MVP | Переезд автора |
| Промежуточный формат, пробный прогон | MVP | Импорт вслепую недопустим |

### Команда
| Фича | Этап | Почему |
|---|---|---|
| Поиск, карточка клиента, выдать дни | MVP | Ежедневная работа |
| Возврат с отметкой «выполнен вручную» | MVP | Возвраты бывают; API провайдера подождёт |
| Возврат через API провайдера и на бонусный счёт | v1 | Вместе с бонусным счётом |
| Рассылка: базовые сегменты, пометка «бот заблокирован» | MVP | Сообщения о работах и новостях |
| Остальные сегменты, отключение рассылок клиентом | v1 | |
| Роль помощника, приглашения | данные — MVP, функция — v1 | Автор работает один |
| Быстрые действия в боте, сообщение клиенту из карточки | v1 | Удобство |

### Оплата

## Критерии приёмки
Каждая фича MVP получает проверяемые утверждения вида «если X, то Y». Фича готова, когда выполнены все её критерии. Задача агенту выдаётся как одна фича с её критериями.

```
### Фича: название
- **Версия:** MVP / v1 / потом
- **Сценарии:** ссылки на 02-scenarios.md
- **Критерии приёмки:**
  - [ ] Если ..., то ...
```
