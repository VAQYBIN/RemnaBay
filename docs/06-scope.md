# 6. Объём версий и критерии приёмки

**Статус:** ⬜ не начат

## Версии
- **MVP** — минимум, с которым автор сам может перевести на проект свой бизнес.
- **v1** — минимум для публичного релиза.
- **Потом** — всё остальное.

## Формат критериев приёмки
Каждая фича получает проверяемые утверждения вида «если X, то Y». Фича готова, когда выполнены все её критерии. Задача агенту выдаётся как одна фича с её критериями.

```
### Фича: название
- **Версия:** MVP / v1 / потом
- **Сценарии:** ссылки на 02-scenarios.md
- **Критерии приёмки:**
  - [ ] Если ..., то ...
```
