# Возможности Telegram Bot API

Актуально на 2026-10-01, Bot API 10.3 (24 августа 2026). Источник — официальный журнал изменений core.telegram.org/bots/api-changelog и страница возможностей core.telegram.org/bots/features.

## Используем
| Возможность | Версия | Где у нас |
|---|---|---|
| Цвет кнопок: danger (красный), success (зелёный), primary (синий) | 9.4 | Целевые и разрушительные действия |
| Иконки — кастомные эмодзи на кнопках | 9.4 | Необязательно; нужен Premium у владельца бота |
| Неактивные кнопки (DisabledButton) | 10.3 | Недоступные действия |
| Кнопка копирования текста (copy_text) | 7.11 | Ссылка на подписку |
| force_reply у инлайн-клавиатуры | 10.3 | Ввод промокода |
| Сущность date_time — дата и время, форматируемые для пользователя | 9.5 | Даты окончания |
| login_url — вход на сайт по инлайн-кнопке | давно | Вход в веб-админку |
| setMyProfilePhoto, setMyName, setMyDescription | 9.4 / ранее | Бренд из админки |
| Rich Messages: заголовки, списки, таблицы, сворачиваемые блоки, медиа, кнопки внутри | 10.1–10.3 | Инструкция, выбор тарифа, карточка подписки |
| Редактирование rich-сообщения через editMessageText (rich_message) | 10.1 | Карточка подписки в живом меню |

## Не используем
- Эфемерные сообщения — работают в группах, а бот работает в личных чатах.
- Потоковые черновики (sendMessageDraft) — для ИИ-ответов.
- Сообщества, гостевой режим, бизнес-боты, управляемые боты.

## Проверить
- Отображение rich-сообщений в старых версиях клиентов, на десктопе и в вебе.
- Можно ли в «живом меню» редактировать обычное сообщение в rich и обратно.
- Отображается ли date_time в часовом поясе клиента.
