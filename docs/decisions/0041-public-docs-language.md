# 0041. Язык публичной документации: сначала русский

- **Дата:** 2026-10-04
- **Статус:** принято

## Контекст
Репозиторий публичный. Нужно решить, на каком языке README на GitHub и документация для операторов. Спека и внутренняя документация уже на русском (`CLAUDE.md`), основная аудитория — русскоязычные операторы Remnawave.

## Решение
- Публичная документация — README на GitHub и документация для операторов — сначала на русском.
- В будущем появится перевод на английский. Срок не определён; идея записана в [backlog.md](../backlog.md).

## Альтернативы
> **Предложение (не утверждено):** альтернативы сформулированы агентом, владелец их не называл.

- Сразу на двух языках — отклонено: двойная работа над документацией, которая на старте часто меняется.
- Только английский — отклонено: основная аудитория и автор говорят по-русски.

## Последствия
- Вопрос «Язык публичной документации» в [open-questions.md](../open-questions.md) закрыт.
