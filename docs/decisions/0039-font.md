# 0039. Шрифт рамы: Golos Text

- **Дата:** 2026-10-04
- **Статус:** принято

## Контекст
Шрифт — часть рамы ([решение 0038](0038-branding.md)) и одинаков во всех магазинах. Требования: полная кириллица, спокойный нейтральный характер, табличные цифры для денег, дат и счётчиков. Админка и страница-переходник не должны зависеть от внешних сервисов: магазин — «один compose, минимум зависимостей» ([позиционирование](../00-positioning.md)).

## Решение
- **Golos Text — одна гарнитура на всё.** Начертания: обычное (400), среднее (500), полужирное (600). Второй гарнитуры для заголовков нет: внимание забирают логотип и цвет оператора.
- **Табличные цифры обязательны** для денег, дат, счётчиков и всех колонок с числами. По умолчанию у шрифта пропорциональные цифры, поэтому табличные включаются явно.
- **Шрифт раздаётся с сервера магазина в составе сборки** — npm-пакет `@fontsource-variable/golos-text`, без внешних CDN. Админка не зависит от Google и не передаёт ему данные посетителей, у страницы-переходника нет внешних запросов.
- **Подмножества:** cyrillic, latin и latin-ext. Знак рубля (₽) у этого шрифта лежит в latin-ext — без него вместо ₽ будет пустой квадрат.
- **Запасной шрифт** — системный интерфейсный шрифт устройства.
- **Лицензия** — SIL Open Font License 1.1. Текст лежит в репозитории: [`third-party-licenses/golos-text-OFL.txt`](../../third-party-licenses/golos-text-OFL.txt). Шрифт упоминается в разделе «О программе» (А12, 1.26).

Проверено по пакету `@fontsource-variable/golos-text` 5.3.0: подмножества cyrillic, cyrillic-ext, latin, latin-ext; ось насыщенности 400–900; ₽ (U+20BD) есть только в latin-ext; табличные цифры (`tnum`) — в latin, откуда берутся цифры 0–9.

## Альтернативы
- **Onest** — запасной вариант того же характера, шире.
- **Manrope, Geologica** — отклонены по характеру.
- **IBM Plex Sans, Commissioner** — в вариативных версиях нет табличных цифр.
- **Inter** — слишком типичен для ИИ-дизайна.
- **Раздача через Google Fonts или другой CDN** — отклонено: внешняя зависимость и передача данных посетителей третьей стороне.
