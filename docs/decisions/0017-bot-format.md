# 0017. Формат бота: классика с точечным rich

- **Дата:** 2026-10-01
- **Статус:** принято

## Контекст
Bot API (актуальная версия — 10.3) за 2026 год получил Rich Messages, неактивные кнопки, цветные кнопки, кнопки копирования, отображение дат и другое. Rich-сообщения становятся трендом в ботах, но формату несколько месяцев. Мини-приложение — отдельный фронтенд, по сути второй канал.

## Решение
- MVP — классический бот: обычные сообщения и инлайн-кнопки. Мини-приложение — в бэклоге, вместе с клиентским сайтом: у них общий фронтенд поверх ядра.
- Rich-сообщения — точечно, «без фанатизма»: инструкция по подключению, выбор тарифа, карточка подписки. Расширение на другие экраны — отдельным решением, если rich покажет себя хорошо.
- В rich-экранах оператор правит поля, а не разметку.
- Используются новые возможности кнопок и сообщений: цвет со смысловыми правилами, неактивные кнопки, копирование ссылки, force_reply для ввода текста, date_time для дат, login_url для входа в веб-админку, смена имени, описания и аватарки бота из админки.
- Иконки-эмодзи на кнопках — необязательно, по желанию оператора (требуют Premium у владельца бота).

## Альтернативы
- Мини-приложение в MVP — отклонено: второй фронтенд, MVP заметно растёт.
- Все экраны на rich — отклонено: зависимость всего бота от нового формата, сложное редактирование текстов оператором.
- Только классика без rich — отклонено: инструкции и сравнение тарифов заметно выигрывают от структуры, тренд очевиден.

## Последствия
- Отображение rich-сообщений нужно проверить на разных клиентах до реализации экранов.
