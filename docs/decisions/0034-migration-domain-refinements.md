# 0034. Миграция и домен: уточнения по ревью

- **Дата:** 2026-10-04
- **Статус:** принято

## Контекст
Независимое ревью нашло пробелы: тариф усыновлённой подписки не определён; промежуточный формат не спроектирован; в домене не хватает сущностей; отзыв ссылки в панели противоречит правилу «ссылка не меняется»; сверка реестра устройств противоречит выводу о дорогих запросах.

## Решение
- **Тариф усыновлённой подписки** задаётся сопоставлением «сквады и лимит устройств → тариф» в пробном прогоне. Без сопоставления — «без тарифа»: продление выбором тарифа. Сквады и лимит устройств выставляются по тарифу при первом применении тарифа; отчёт заранее показывает, у скольких подписок параметры изменятся.
- **Промежуточный формат** — [migration-format.md](../migration-format.md). Адаптер читает базу старого бота только на чтение. Пользователи панели вне файла усыновляются в том же прогоне. Клиент из файла без пользователя в панели — обычный клиент; триал по признаку из файла.
- **Домен дополнен:** активация промокода, реферальный код, рассылка, напоминание, сессия, приглашение; параметры тарифа зафиксированы.
- **Ссылка:** магазин сам её никогда не меняет; отозванную в панели — принимает и сообщает клиенту.
- **Сверка реестра устройств** — только для триальных подписок, запросом списка устройств одного пользователя.
