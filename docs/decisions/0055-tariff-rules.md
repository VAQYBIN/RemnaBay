# 0055. Тариф: цена, сквады, удаление

- **Дата:** 2026-10-07
- **Статус:** принято

## Контекст
На этапе 5 (блок 2) реализация показала три вопроса, на которые спека не отвечала:
- можно ли сохранить тариф без сквадов — клиент заплатит и получит подписку, которая никуда не подключается;
- можно ли продавать тариф по цене 0;
- можно ли удалить тариф, по которому не было подписок, но был открыт счёт (или который указан в промокоде): критерий 2.8 говорит только о подписках.

## Решение
- **Хотя бы один сквад.** Тариф без сквадов не сохраняется — как и триал ([04-operator-settings.md](../04-operator-settings.md)).
- **Цена больше нуля.** Бесплатный доступ даёт триал; платёж с нулевой суммой бывает только при скидке 100% по промокоду.
- **Удаляется только тариф, который ещё не использовался:** по нему не было ни подписок, ни платежей (в любом состоянии, включая неоплаченные и истёкшие счета) и он не указан в промокодах. Иначе — только архив. Админка объясняет, почему удалить нельзя.

## Альтернативы
- Тариф без сквадов — отклонено: клиент платит за подписку без доступа.
- Бесплатный тариф — отклонено: для бесплатного доступа есть триал с защитой от злоупотреблений (0013).
- Удаление тарифа, по которому был только счёт, с отвязкой платежа — отклонено: если счёт оплатят, применять будет нечего; промокод, ограниченный этим тарифом, потерял бы ограничение.

## Последствия
- Правила проверяют API админки и форма тарифа. Ограничения базы на тарифы не меняются (`price >= 0`, сквады могут быть пустыми): в MVP тарифы создаются только в админке.
- Связанные вопросы закрыты в [open-questions.md](../open-questions.md).
