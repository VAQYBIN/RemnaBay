# 0009. Четыре фиксированных типа тарифа

- **Дата:** 2026-10-01
- **Статус:** принято

## Контекст
Тарифы бывают очень разными: только трафик, только дни, дни и трафик, трафик на весь срок или с ежемесячным сбросом. Свободная комбинация параметров порождает вопросы «а что будет при продлении, если…», на которые у системы нет ответа.

## Решение
В панели у трафика есть лимит, счётчик и стратегия сброса. Отсюда две природы трафика: квота на период (обнуляется по расписанию) и пакет (без сброса, накапливается). Оператор выбирает один из четырёх типов тарифа: срок + безлимит, срок + квота на период, срок + пакет, только пакет. У каждого типа ровно одно поведение при покупке и продлении. Остаток пакета сохраняется всегда. Докупка трафика — это покупка тарифа «только пакет» для существующей подписки с пакетным трафиком, без отдельной системы аддонов. Тариф «только пакет» ставит дату окончания в 2099 году — клиентские приложения показывают её как «бессрочно».

## Альтернативы
- Свободная настройка параметров — отклонено: непредсказуемое поведение.
- Отдельная система аддонов — отклонено: докупка покрывается пакетами.
- Докупка трафика к квоте на период — отклонено: лимит в панели одно число, при сбросе докупленное либо останется навсегда, либо магазину придётся откатывать лимит по расписанию.
- Сгорание остатка пакета после истечения — отложено: можно добавить настройкой, если операторы попросят.

## Последствия
- Клиенту с квотой, которому не хватило трафика, предлагается смена тарифа.
- Тип тарифа покрывает большинство практических случаев; нишевые схемы — не в ядре.
