# 0050. Клиент админки из OpenAPI: openapi-typescript, openapi-fetch, openapi-react-query

- **Дата:** 2026-10-06
- **Статус:** принято

## Контекст
Решения [0022](0022-stack-foundation.md) и [0025](0025-admin-frontend.md) требуют генерировать типизированный клиент админки из OpenAPI-схемы FastAPI, чтобы бэкенд и фронтенд не расходились. Инструмент в [решении 0027](0027-versions.md) не был выбран. Стек админки — React 19, TypeScript (строгий режим), TanStack Query. Код пишут агенты, ревьюит владелец: чем меньше сгенерированного кода, тем меньше того, что нужно читать и сопровождать.

## Решение
- **openapi-typescript** генерирует из схемы только типы — один файл.
- **openapi-fetch** выполняет запросы по этим типам: путь, параметры, тело и ответ проверяются компилятором.
- **openapi-react-query** — тонкая обёртка над TanStack Query: `$api.useQuery("get", "/api/…/{id}", { params: { path: { id } } })`.
- Схема для генерации берётся при сборке, а не с работающего магазина ([решение 0049](0049-stage-4-preparation.md)); сборка админки и проверка типов падают, если бэкенд и админка разошлись.

## Альтернативы
Сравнение — октябрь 2026, по документации и открытым сравнениям генераторов.
- **Hey API (`@hey-api/openapi-ts`)** с плагином TanStack Query — отклонено с небольшим отрывом. Его советует документация FastAPI, вызовы короче и по имени операции. Но версия до 1.0 (0.99), вывод и настройки меняются между версиями, сгенерированного кода больше.
- **Orval** — отклонено: хук на каждую операцию, тысячи файлов на большой схеме; экосистема уходит от сгенерированных хуков к готовым настройкам запросов.
- **Kubb** — отклонено: больше всего сгенерированного кода, медленная генерация, `any` в выводе.
- **OpenAPI Qraft**, **typed-openapi** — отклонено: маленькие сообщества.
- **OpenAPI Generator** — отклонено: нужна Java при сборке, громоздкий код.

## Последствия
- Зависимости админки: `openapi-typescript` (для разработки), `openapi-fetch`, `openapi-react-query` — через npm с lock-файлом (0027).
- В вызовах пишутся пути API, а не имена функций: путь совпадает с маршрутом FastAPI, его легко найти в бэкенде; переименование маршрута ловит проверка типов.
- `openapi-react-query` — версия до 1.0 (0.5) и обновляется реже остальных; если она перестанет поддерживаться, её заменяет `queryOptions` из TanStack Query поверх `openapi-fetch` без смены генератора.
