# 0018. Языки: тексты по ключу с первого дня

- **Дата:** 2026-10-01
- **Статус:** принято

## Контекст
Telegram передаёт боту язык приложения пользователя и рекомендует подстраиваться под него. Автору для переезда нужен только русский; сообществу со временем понадобятся другие языки.

## Решение
- Каждый текст бота с первого дня хранится по ключу и языку. Тексты в коде не пишутся.
- MVP — русский. Английский — в v1, к публичному релизу. Другие языки — по запросу сообщества.
- Оператор выбирает язык бота по умолчанию. Если для языка клиента есть перевод, бот использует его; иначе — язык по умолчанию.
- Тексты по умолчанию — на «вы», нейтрально-дружелюбно, без канцелярита. Оператор может переписать любой текст.
- Тексты с числами используют правила множественного числа языка («1 день», «3 дня», «5 дней»).

## Альтернативы
- Только русский, тексты в коде — отклонено: добавление языка превращается в переделку.
- Русский и английский в MVP — отклонено: работа, не нужная для переезда автора.

## Последствия
- Тексты по умолчанию описаны в [03-bot-texts.md](../03-bot-texts.md) и служат исходным набором для переводов.
