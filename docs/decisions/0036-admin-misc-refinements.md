# 0036. Админка и прочее: уточнения по ревью

- **Дата:** 2026-10-04
- **Статус:** принято

## Контекст
Независимое ревью нашло: MVP на тестовом сервере нельзя проверить, пока магазин закрыт; нет поведения при повторном закрытии; неясно, как получить кнопку входа из бота; не определены часовой пояс и смысл цифр на главной; не принят явно компромисс блокировок в очереди; не описана смена владельца в `.env`; пункты чек-листа «Триал» и «Бренд» бессмысленны в текущем виде.

## Решение
- **Режим проверки:** пока магазин закрыт, бот работает для команды и тестировщиков (список Telegram ID в настройках).
- **Закрытие открытого магазина:** новые покупки, продления и триалы недоступны; подписки, ссылки и инструкции видны; пришедшие оплаты применяются; напоминания приостановлены.
- **`/admin`** — скрытая команда: участнику команды бот присылает кнопку входа.
- **Главная:** часовой пояс магазина — настройка (по умолчанию Москва); «новые клиенты» — впервые открыли бот, без усыновлённых; «активные подписки» — платные, триалы отдельно.
- **Приветственный бонус (v1)** тратится только как скидка — фармить его пустыми аккаунтами бессмысленно.
- **Очередь:** запрос к панели — с коротким таймаутом; «занятость» подписки для порядка — на отдельной служебной отметке, а не на строке подписки.
- **Владелец из `.env`** при каждом запуске гарантированно является владельцем; другие владельцы не удаляются.
- **Чек-лист:** «Триал» — информационный пункт; «Бренд» — название и логотип.
