# 0023. База данных: PostgreSQL, SQLAlchemy, Alembic

- **Дата:** 2026-10-01
- **Статус:** принято

## Контекст
Деньги требуют транзакций; конфиги и данные вебхуков удобно хранить в JSON; обновления должны проходить спокойно. Remnawave работает на PostgreSQL — у оператора эта технология уже есть.

## Решение
- **PostgreSQL** — отдельная база магазина, не таблицы в базе панели.
- **SQLAlchemy 2** в асинхронном режиме с типизированными моделями.
- **Alembic** — миграции схемы.

## Альтернативы
- SQLite — отклонено: несколько процессов (бот, API, воркер) и денежные транзакции.
- Общая база с панелью — отклонено: обновления панели и магазина не должны зависеть друг от друга.

## Последствия
- Очередь фоновых задач по возможности тоже живёт в PostgreSQL — выбор после эксперимента, см. [research/spike-task-queue.md](../research/spike-task-queue.md).
