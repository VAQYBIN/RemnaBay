# 0035. Триал и сообщения клиенту: уточнения по ревью

- **Дата:** 2026-10-04
- **Статус:** принято

## Контекст
Независимое ревью нашло: поведение отключённой в панели подписки не описано; в момент окончания клиент получал бы два-три сообщения; трафик триала и покупка после триала описаны не до конца; «ровно один раз» для сообщений технически недостижимо.

## Решение
- **Отключённая в панели подписка:** магазин её не включает; «Продлить» нет; напоминаний нет; пришедшая оплата применяется к сроку, команда получает уведомление.
- **Одно сообщение в момент окончания:** у платной подписки — «Подписка истекла» (напоминание «в момент окончания» убрано из значений по умолчанию и подавляется при совпадении); у триала — «Пробный период закончился». У напоминания триала свой текст.
- **Трафик триала** не сбрасывается. Исчерпание — событие MVP: «Трафик пробного периода закончился» и «Купить подписку». При покупке после триала лимит и стратегия трафика — по тарифу, счётчик обнуляется.
- **Покупка с триала:** «Купить подписку» в карточке триальной подписки и в главном меню; «Попробовать бесплатно» — внизу экрана выбора тарифа для тех, кому триал доступен.
- **Панель недоступна при отправке напоминания** — напоминание откладывается; из наступивших отправляется самое позднее.
- **Сообщения клиенту — не больше одного раза:** при сбое в момент отправки лучше потерять сообщение, чем отправить дважды.
- **«Продлить» в рассылке** у клиента без подписок ведёт к выбору тарифа.
