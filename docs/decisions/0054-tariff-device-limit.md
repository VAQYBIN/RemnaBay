# 0054. У тарифа всегда есть лимит устройств

- **Дата:** 2026-10-07
- **Статус:** принято

## Контекст
Критерий 2.1 называет лимит устройств параметром тарифа, но не говорит, может ли тариф быть без ограничения: в панели у пользователя лимит может быть не задан. Модель данных требовала число и допускала 0, смысл нуля не был определён. Вопрос появился на этапе 2 (модель данных) и нужен к блоку 2.

## Решение
Тариф не может быть без лимита устройств: лимит обязателен и не меньше 1. База отклоняет тариф с лимитом меньше 1, админка не даёт такой сохранить.

## Альтернативы
- Тариф без ограничения устройств (0 или пусто — «без лимита») — отклонено: защита триала (0013) и управление устройствами (блок 6) опираются на лимит. Вернуться к варианту можно по запросу сообщества.

## Последствия
- Миграция меняет ограничение базы на тарифы: `device_limit >= 1` вместо `>= 0`.
- Любое применение тарифа к подписке записывает в панель конкретный лимит устройств (3.37).
