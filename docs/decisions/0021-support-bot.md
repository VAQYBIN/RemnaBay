# 0021. Бот поддержки — необязательный компонент

- **Дата:** 2026-10-01
- **Статус:** принято

## Контекст
У части операторов поддержка уже налажена: личный аккаунт, группа, helpdesk. Другим нужно готовое решение.

## Решение
В MVP поддержка — контакт, который задаёт оператор (кнопка «Поддержка»). В v1 проект предлагает собственного бота поддержки как необязательный компонент поверх ядра, по аналогии с клиентским сайтом: оператор выбирает — свой контакт или бот поддержки проекта.

## Альтернативы
- Встроенная поддержка, обязательная для всех — отклонено: ломает уже работающие решения операторов.
- Поддержка в MVP — отклонено: для переезда автора хватает контакта.

## Последствия
- Бот поддержки проектируется при подготовке v1; переписку стоит показывать в карточке клиента рядом с подписками и платежами.
