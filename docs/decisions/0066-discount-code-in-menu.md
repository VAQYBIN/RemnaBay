# 0066. Промокод на скидку, введённый через меню

- **Дата:** 2026-10-15
- **Статус:** принято

## Контекст
Промокод на скидку вводится на экране подтверждения покупки или продления (8.4), промокод на дни — через «Ввести промокод» в главном меню (8.10). Для кода на дни, введённого на экране подтверждения, есть подсказка `promo.error.days_on_confirm` (8.9). Для обратного случая — кода на скидку, введённого из меню, — в спеке не было ни поведения, ни текста. Вопрос появился на этапе 9.

## Решение
- **Зеркальная подсказка.** Если через «Ввести промокод» в меню ввести действующий промокод на скидку, клиент видит `promo.error.discount_in_menu`: «Этот промокод даёт скидку. Введите его на экране подтверждения, когда будете покупать или продлевать подписку.»
- **Попытка неверной не считается** (8.13): код настоящий, клиент просто ввёл его не там. Удачной она тоже не считается — счётчик неверных попыток не меняется.
- Подсказка показывается после тех же проверок, что и для кода на дни на экране подтверждения: несуществующий, отключённый, истёкший или исчерпанный код по-прежнему получает нейтральный текст (8.12).

## Альтернативы
- Запомнить код и подставить его на следующем экране подтверждения — отклонено: нужно хранить код у клиента и решать, когда он «забывается».
- Сразу вести клиента к выбору тарифа или продлению со скидкой — отклонено: при нескольких подписках и при триале путь неочевиден.
