# 0012. Смена тарифа сразу, с перерасчётом через бонусный счёт

- **Дата:** 2026-10-01
- **Статус:** принято

## Контекст
Клиенту нужно сменить тариф: повысить, понизить, уйти с архивного. Главный вопрос — что делать с оплаченным, но неиспользованным временем и трафиком старого тарифа.

## Решение
Смена происходит сразу, в обоих направлениях. Неиспользованная стоимость старого тарифа зачисляется на бонусный счёт, после чего клиент покупает новый тариф, и бонусы применяются автоматически: при повышении клиент доплачивает разницу, при понижении излишек остаётся на счёте.

Неиспользованная стоимость считается по модели отрезков: возвращается только фактически заплаченное и неиспользованное. Подаренные дни, дни, добавленные в панели напрямую, и дни, перенесённые при миграции, стоят ноль. Текущая цена тарифа в расчёте не участвует. По времени — для безлимита и квоты; по трафику — для «только пакета»; для «срок + пакет» — меньшая из долей по времени и по трафику.

Новый тариф начинается с чистого листа, счётчик трафика обнуляется. Исключение — смена между тарифами с квотой: счётчик сохраняется.

## Альтернативы
- Смена со следующего продления — отклонено: не помогает клиенту, которому трафик нужен сейчас.
- Повышение сразу, понижение со следующего периода — отклонено: две разные механики и лишний вопрос у клиента.
- Расчёт по текущей цене тарифа — отклонено: смена тарифа становится способом заработать на изменении цен и акциях.
- Для «срок + пакет» расчёт только по времени — отклонено: выбрал весь трафик, сменил тариф и получил назад почти всю стоимость.
- Перенос стоимости мигрированных дней — отклонено: магазин не видел этих платежей; оператор может компенсировать бонусами.

## Последствия
- Магазин хранит для каждой подписки отрезки срока и пакетов с их стоимостью.
- Частота смены тарифа не ограничивается: деньги не выходят из системы, неиспользованное остаётся бонусами.
