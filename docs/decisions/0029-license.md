# 0029. Лицензия MIT

- **Дата:** 2026-10-04
- **Статус:** принято

## Контекст
Проект открытый; цель — помочь другим операторам быстро начать своё дело. Лицензию нужно выбрать до первой публикации репозитория.

## Решение
Лицензия MIT. Файл `LICENSE` в корне репозитория.

## Альтернативы
- Копилефт-лицензии (GPL, AGPL) — отклонено: обязывают открывать изменения, что отпугивает операторов, дорабатывающих магазин под себя; MIT типична для экосистемы Remnawave.

## Последствия
- Любой может использовать, менять и распространять проект, в том числе в коммерческих целях, сохраняя уведомление об авторстве.
