# 0022. Основа стека: Python, FastAPI, aiogram

- **Дата:** 2026-10-01
- **Статус:** принято

## Контекст
Код пишут ИИ-агенты, владелец ревьюит. Владелец привык к Python, FastAPI и aiogram и читает Python увереннее всего. Прошлая попытка на незнакомом стеке (TypeScript, NestJS, grammY) оставляла ощущение, что агент «делает что-то своё»: проверить написанное было трудно.

## Решение
- **Ядро и HTTP-сервер** (вебхуки, API админки, страница-переходник, вход) — Python, FastAPI.
- **Бот** — aiogram 3 (поддерживает Bot API 10.3).
- **Интеграция с панелью** — уточнено [решением 0028](0028-panel-client.md): SDK сообщества `remnawave-api` (sm1ky) за собственным интерфейсом магазина. *Исправление: изначально здесь был указан remnawave/python-sdk как поддерживаемый; на деле он в архиве и не поддерживается.*
- **Фронтенд админки** — TypeScript (подробности — отдельным решением).

## Альтернативы
- TypeScript, NestJS, grammY — отклонено. Плюсы: единый язык с фронтендом, строгая типизация, контракт панели прямо из её исходников. Перевесили: владелец не читает этот стек уверенно; боты продажи VPN в экосистеме Remnawave в основном на Python, и адаптеры миграции удобнее писать тем же людям.
- Go — отклонено: незнакомый владельцу язык; скорость не нужна при масштабе небольших операторов.

## Последствия
- **Строгая типизация обязательна:** pyright в строгом режиме; код, не прошедший проверку типов, не считается готовым.
- **Pydantic на всех границах:** API, вебхуки, конфиг Subscription Page, промежуточный формат миграции, контракт провайдера.
- **Типизированный клиент админки генерируется из OpenAPI-схемы FastAPI** — бэкенд и фронтенд не расходятся.
- Эти правила попадут в `CLAUDE.md` при переходе к коду.
