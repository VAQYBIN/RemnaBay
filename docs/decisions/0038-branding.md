# 0038. Брендирование: рама и бренд оператора

- **Дата:** 2026-10-04
- **Статус:** принято

## Контекст
Магазин разворачивает каждый оператор под своим именем: клиенты видят бренд оператора, а не RemnaBay. При этом у продукта должен быть один узнаваемый и проверенный облик, который не разваливается от того, что оператор задал свой цвет. До этого решения бренд в настройках был только названием, логотипом и приветственным текстом; что из облика можно менять, а что нет, не было определено.

## Решение

### Рама и бренд оператора
Оформление делится на две части:
- **Рама** — постоянная часть, одна для всех магазинов: материал (жидкое стекло), сетка, шрифты, отступы, движение, компоненты. Оператор её не меняет.
- **Бренд оператора** — переменная часть: название, логотип, фирменные цвета. Задаётся в настройках «Бренд».

Направление рамы описано в [design/DESIGN.md](../design/DESIGN.md).

### Настройки бренда
- **Основной фирменный цвет** — обязателен; по умолчанию — основной цвет RemnaBay.
- **Дополнительный фирменный цвет** — необязателен; используется для второстепенных акцентов: выделений, бейджей, графиков. Никогда не используется для кнопки целевого действия и не заменяет смысловые цвета. Если дополнительный цвет не задан, второстепенные акценты берутся из шкалы основного цвета, а не из палитры RemnaBay: иначе чужой песочный цвет смешается с цветом оператора.
- **Логотип:** квадратный знак обязателен, горизонтальный логотип — по желанию. Файлы — SVG или PNG с прозрачным фоном; квадратный знак — не меньше 512×512 пикселей, он же предлагается как аватар бота. Горизонтальный логотип показывается там, где есть место (шапка админки на широком экране, экран входа, страница-переходник), а без него — знак и название текстом.
- **Цвета RemnaBay по умолчанию** — палитра «Бухта»: основной — морская бирюза `#1FA4A0`, дополнительный — тёплый песок `#E9B872`.
- **Пока название и знак не заданы** (первый вход), экран входа и шапка админки показывают название и знак RemnaBay — так же, как фирменный цвет по умолчанию.

### Правила цвета
- **Шкала строится из основного цвета:** из одного значения система получает все оттенки, которые нужны раме (фоны, обводки, наведение, нажатие, текст на цвете). Оператор не подбирает оттенки вручную.
- **Контраст обеспечивается автоматически с сохранением оттенка:** если цвет оператора не даёт читаемого текста или различимой кнопки, система меняет его светлоту и насыщенность, но не тон. Оператор задаёт «какой цвет», рама гарантирует «читается». Порог — WCAG 2.2 AA: 4,5:1 для обычного текста, 3:1 для крупного текста и элементов интерфейса.
- **Близость к смысловому цвету:** если основной цвет по тону близок к смысловому (например, бирюза к «успеху»), админка предупреждает при сохранении, но не запрещает.
- **Смысловые цвета не брендируются:** успех, внимание, ошибка одинаковы во всех магазинах и принадлежат раме.
- **Обе темы — в токенах:** светлая и тёмная описаны одним набором токенов; бренд оператора применяется к обеим. По умолчанию — тёмная.

### Тема
- Админка и страница-переходник следуют теме устройства; если тема устройства неизвестна — тёмная.
- В админке есть переключатель «Системная / Светлая / Тёмная».

### Поверхности
| Поверхность | Чей бренд |
|---|---|
| Веб-админка и экран входа | Бренд оператора. RemnaBay — только в разделе «О программе» |
| Страница-переходник | Только бренд оператора; упоминания RemnaBay нет |
| Бот | Название и аватар (знак) — бренд оператора; цвета кнопок — смысловые цвета Telegram, не брендируются (принципы бота в [03-screens.md](../03-screens.md)) |
| Будущие клиентский сайт и мини-приложение | Бренд оператора на тех же токенах рамы |

«О программе» — отдельный пункт навигации админки, доступный всем ролям.

## Альтернативы
- **Полная настройка оформления оператором** (свои шрифты, радиусы, произвольные цвета для каждого элемента) — отклонено: противоречит принципу «разумные значения по умолчанию важнее бесконечной гибкости»; каждый магазин превращается в непроверенную тему, контраст и смысл цветов не гарантированы.
- **Один фиксированный облик RemnaBay без бренда оператора** — отклонено: клиенты оператора видят чужое имя; оператор продаёт свой сервис, а не RemnaBay.
- **Брендированные смысловые цвета** — отклонено: «ошибка» в цвет бренда перестаёт читаться как ошибка; смысл важнее единообразия с брендом.
- **Подпись «работает на RemnaBay» на странице-переходнике** — отклонено: это клиентская поверхность, клиент оператора не должен видеть чужое имя.
- **Полная смена темы (рамы)** — отложено в [backlog.md](../backlog.md).
