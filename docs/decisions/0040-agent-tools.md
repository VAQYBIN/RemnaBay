# 0040. Рекомендуемые инструменты агента

- **Дата:** 2026-10-04
- **Статус:** принято

## Контекст
Код пишут ИИ-агенты (Claude Code). Качество их работы зависит от инструментов: актуальная документация библиотек вместо знаний по памяти, проверка типов, просмотр интерфейса в браузере, ревью изменений. Если у владельца и контрибьюторов разные наборы, результат и отчёты агентов будут разными.

## Решение
Рекомендуемый набор инструментов агента:

| Инструмент | Вид | Зачем | Где подключён у владельца |
|---|---|---|---|
| Context7 | MCP (плагин) | Актуальная документация библиотек и их API | на уровне пользователя |
| shadcn | MCP | Компоненты shadcn/ui для админки ([решение 0027](0027-versions.md)) | в проекте, `.mcp.json` |
| Playwright | плагин | Проверка админки и страницы-переходника в браузере, в том числе на ширине 360 px (1.16) | в проекте, `.claude/settings.json` |
| pyright-lsp | плагин | Проверка типов Python в строгом режиме по ходу работы ([решение 0022](0022-stack-foundation.md)) | в проекте, `.claude/settings.json` |
| typescript-lsp | плагин | Проверка типов TypeScript админки | на уровне пользователя |
| security-guidance | плагин | Подсказки по безопасности при правке кода | на уровне пользователя |
| pr-review-toolkit | плагин | Ревью изменений перед слиянием | в проекте, `.claude/settings.json` |
| Скиллы из `skills-lock.json` | скиллы | `emil-design-eng`, `git-guardrails-claude-code`, `grill-me`, `impeccable`, `tdd`, `web-design-guidelines` | в проекте, `.claude/skills/` |

- Владелец ставит часть инструментов на уровне пользователя (Context7, typescript-lsp, security-guidance), остальные подключены в проекте.
- Контрибьюторам рекомендуется поставить тот же набор, включая инструменты уровня пользователя.
- **Перед использованием API библиотеки агент сверяется с документацией через Context7, а не пишет по памяти** — правило в `CLAUDE.md`, раздел «Правила разработки».

## Альтернативы
> **Предложение (не утверждено):** альтернативы сформулированы агентом, владелец их не называл.

- **Без рекомендуемого набора** — отклонено: агенты у разных людей работают по-разному, ошибки «по памяти» в API библиотек повторяются.
- **Обязательный набор с проверкой** — отклонено: инструменты агента — среда разработчика, а не часть продукта; магазин от них не зависит.

## Последствия
- Правило о Context7 добавлено в `CLAUDE.md`.
- Когда появится `CONTRIBUTING.md`, список переносится туда как рекомендация для контрибьюторов.
- Проектная часть набора работает у контрибьютора, только если `.mcp.json`, `.claude/settings.json`, `.claude/skills/` и `skills-lock.json` лежат в репозитории.
