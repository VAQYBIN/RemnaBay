# 0003. Ядро и каналы: бот — основной, сайт — необязательный

- **Дата:** 2026-09-30
- **Статус:** принято

## Контекст
Не всем операторам нужен клиентский сайт, но части из них он нужен. Разрабатывать сайт без готового ядра сложно.

## Решение
Продукт состоит из ядра и каналов. Ядро не зависит от Telegram. Telegram-бот — основной и обязательный канал, входит в MVP. Клиентский веб-сайт — отдельный необязательный канал на том же ядре, появится после MVP. Веб-админка оператора — не клиентский сайт; входит в MVP согласно позиционированию.

## Альтернативы
- Бот и сайт как единое обязательное целое — отклонено: навязывает сайт тем, кому он не нужен.
- Сайт в MVP — отклонено: без ядра его сложно спроектировать.

## Последствия
- Клиент — самостоятельная сущность; Telegram-аккаунт — один из способов входа.
- Платёжные сценарии описываются без привязки к каналу; канальные особенности помечаются явно.
- Тексты и оформление настраиваются отдельно для каждого канала.
