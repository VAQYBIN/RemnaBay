# 0025. Фронтенд админки: React-приложение на Vite

- **Дата:** 2026-10-03
- **Статус:** принято

## Контекст
Веб-админка должна быть удобной на телефоне (1.16), типизированно связанной с бэкендом (решение 0022) и не добавлять сервисов в развёртывание (позиционирование: «один compose, минимум зависимостей»).

## Решение
- Админка — React-приложение на TypeScript, собранное Vite в статические файлы.
- Статические файлы отдаёт тот же FastAPI-сервер, который обслуживает API админки. Отдельного сервера для фронтенда в продакшене нет.
- Клиент API для админки генерируется из OpenAPI-схемы FastAPI.
- Строгий режим TypeScript.
- Конкретные библиотеки фронтенда (компоненты интерфейса, маршрутизация, работа с данными) и их версии фиксируются в решении о версиях.

## Альтернативы
- Next.js — отклонено: требует отдельного Node-сервера в продакшене; его сильные стороны (серверный рендеринг, поисковая оптимизация) админке за логином не нужны.
- Страницы, которые рендерит Python (шаблоны, htmx) — отклонено: скромнее интерфейс, нет типизированной связи с бэкендом, сложнее собрать удобную мобильную админку.

## Последствия
- В репозитории две части: бэкенд на Python и фронтенд админки на TypeScript; собирается всё в один образ.
