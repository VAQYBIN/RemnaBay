# 0037. Уточнения по второму ревью

- **Дата:** 2026-10-04
- **Статус:** принято

## Контекст
Повторное независимое ревью: из 41 пункта первого ревью 33 закрыты, 8 закрыты частично; исправления создали новые стыки, в основном между повторами операций, «Требуют внимания» и сообщениями клиенту.

## Решение
- **Применение тарифа записывает в панель все параметры доступа** (сквады, лимит устройств, лимит и стратегию трафика) — при покупке, продлении и смене. Ручные правки в панели — факт до следующего применения тарифа. Особый набор для клиента — через отдельный тариф.
- **Недоступность панели — не окончательный провал:** операции ждут восстановления и продолжаются сами; команда получает одно уведомление о простое.
- **«Требуют внимания» — все проваленные операции,** не только платежи; действия «Повторить» и «Отменить». Отмена снимает ожидание операций подписки; триал не считается использованным, активация промокода не расходуется.
- **Отключённая подписка:** решает, кто отключил. Отключённую оператором магазин не включает; отключённую самим магазином (отзыв триала, v1) покупка включает.
- **Пауза магазина:** не отправляются сообщения, предлагающие купить; после открытия — одно последнее актуальное по каждой подписке; промокод на дни работает.
- **Согласование:** «оплачен» на время повторов; исключение о сообщениях после возврата — для любого возврата, который заканчивает подписку; возврат неприменённого или неизвестного платежа — на всю сумму; повтор сообщения — только при однозначном отказе Telegram; конфликт Telegram ID при импорте; отмена счёта клиентом; привязка неизвестного платежа с выбором тарифа.
- **Номера критериев постоянны;** порядок строк — по темам.
