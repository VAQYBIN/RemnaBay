# 0001. Сначала спецификация, потом код

- **Дата:** 2026-09-30
- **Статус:** принято

## Контекст
Предыдущие попытки начинались с бренда, UI и стека, а продуктовое ядро оставалось размытым. ИИ-агенты заполняли пробелы собственными решениями, и проект переставал ощущаться своим.

## Решение
Спецификация функционала живёт в репозитории, в `docs/`, и является источником истины. Код не пишется, пока MVP не утверждён. Агенты не принимают продуктовых решений: вопросы без ответа уходят в `open-questions.md`.

## Альтернативы
Спека во внешнем документе — отклонено: не версионируется вместе с проектом и не видна агентам напрямую.

## Последствия
Первый работающий код появится позже, но каждая фича будет выдаваться агенту с критериями приёмки.
