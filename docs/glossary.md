# Глоссарий

| Термин | Значение |
|--------|----------|
| Ядро | Часть продукта, не зависящая от канала: клиенты, подписки, платежи, бонусы, синхронизация с панелью, журнал |
| Канал | Способ, которым клиент взаимодействует с ядром: Telegram-бот, клиентский сайт |
| Веб-админка | Рабочее место команды оператора; не клиентский сайт |
| Оператор | Владелец VPN-бизнеса, который разворачивает и настраивает магазин |
| Команда | Люди с доступом к веб-админке: владельцы и помощники |
| Владелец | Роль команды с полным доступом |
| Помощник | Роль команды для работы с клиентами, без доступа к настройкам, деньгам и рассылкам |
| Клиент | Тот, кто платит и управляет подписками |
| Способ входа | То, по чему магазин узнаёт клиента: Telegram-аккаунт, позже email |
| Действующее лицо | Участник события в журнале без доступа: система, панель, платёжный провайдер |
| Панель | Панель управления Remnawave |
| Магазин | Этот проект: ядро, каналы и админка |
| Подписка | Коммерческая обёртка над пользователем панели |
| Тариф | То, что продаётся: тип, параметры доступа и цена |
| Тип тарифа | Один из четырёх: срок + безлимит, срок + квота на период, срок + пакет, только пакет |
| Квота на период | Лимит трафика, который панель обнуляет по расписанию; остаток не переносится |
| Пакет | Лимит трафика без сброса; накапливается при покупках, остаток сохраняется |
| Докупка пакета | Покупка тарифа «только пакет» для существующей подписки с пакетным трафиком |
| Якорь сброса | Дата создания пользователя в панели, от которой считается сброс «раз в месяц от даты создания» |
| Архивный тариф | Тариф, который не продаётся новым клиентам, но продлевается текущими, пока подписка активна |
| Закрытый тариф | Тариф, который нельзя продлить никому; действующие подписки работают до оплаченной даты |
| Отрезок срока | Часть срока подписки, добавленная одним продлением, со своей фактически заплаченной стоимостью; у подаренных отрезков стоимость нулевая |
| Неиспользованная стоимость | Заплаченная и ещё не использованная часть отрезков; при смене тарифа зачисляется на бонусный счёт |
| Тариф-преемник | Тариф, который предлагается клиенту вместо архивного или закрытого |
| Чёрный список | Список Telegram ID, которым не выдаётся триал: собственный список оператора и подключённые внешние списки |
| Реестр устройств | Учёт устройств, подключавшихся к подпискам клиентов; используется для проверки триала |
| Сквад | Понятие Remnawave: группа инбаундов/нод, к которой получает доступ пользователь |
| Бонусный счёт | Счёт клиента, куда система складывает то, что должна ему; нельзя пополнить и вывести |
| Смешанная оплата | Оплата частично бонусами, частично деньгами |
| Усыновление | Привязка уже существующего пользователя панели к клиенту магазина |
| Адаптер | Модуль, переводящий данные чужого бота в промежуточный формат импорта |
| Промежуточный формат | Документированный формат данных, с которым работает импорт |
| Пробный прогон | Отчёт импорта без применения изменений |
| Сквозное правило | Правило из начала [02-scenarios.md](02-scenarios.md), которое действует во всех сценариях |
| Чек-лист первичной настройки | Список того, что ещё не настроено, на главной странице админки; открытие магазина — по кнопке владельца |
| «Требуют внимания» | Список платежей и операций, которые система не смогла завершить сама и которые разбирает команда |
| Валюта учёта | Единственная валюта магазина: в ней хранятся цены, выручка, бонусы, стоимость отрезков и возвраты |
| Контракт провайдера | Набор действий, которые магазин ожидает от любого платёжного провайдера; новый провайдер подключается через него |
| Клиент панели | Собственный интерфейс магазина для работы с панелью; внутри — SDK `remnawave-api` |
| Конфиг Subscription Page | Настройка страницы подписки в панели: платформы, приложения, шаги; из неё собирается инструкция в боте |
| Внешний сквад | Понятие Remnawave; через него пользователю назначается конфиг Subscription Page |
| Страница-переходник | Веб-страница магазина, через которую из Telegram открываются диплинки приложений |
| Сегмент | Аудитория рассылки — фильтр по данным клиентов |
