# Бэклог: после MVP

Идеи, которые осознанно отложены. Это не спецификация: пока идея здесь, она не проектируется и не реализуется. Когда до неё доходит очередь, она проходит обычный путь — сценарии, решения, критерии приёмки.

## Клиенты и маркетинг
- **Сегментация клиентов** — «горячие», «холодные» и другие сегменты по поведению. Образец — реализация в Remnawave Minishop. Ложится на механику рассылок: аудитория рассылки уже описана как сегмент.
- **Автоматические кампании возврата** — рассылки клиентам, которые давно не заходили или не продлили подписку. По сути — рассылка по сегменту, запускаемая по расписанию.
- **Отложенные рассылки.**

## Оплаты и подписки
- **Чеки ЮКассы для ИП и ООО** — новая реализация модуля чеков. См. [решение 0030](decisions/0030-receipts.md).
- **Показ цен в валюте клиента** — справочно, с пометкой «≈», никогда не для расчётов. См. [решение 0020](decisions/0020-currency.md).
- **Цены тарифа в нескольких валютах, заданные оператором вручную** — без живого курса. Понадобится, например, вместе с оплатой в Telegram Stars.
- **Новые провайдеры:** Telegram Stars, CryptoBot (принимает счёт в фиатной валюте и сам пересчитывает в криптовалюту) и другие — через контракт провайдера.
- **Автопродление** — сохранённые карты у провайдеров или другой механизм.
- **Сгорание остатка пакета** через N дней после истечения — как настройка оператора, если операторы попросят. См. [решение 0009](decisions/0009-tariff-types.md).
- **Передача подписки и делегирование доступа.** См. [open-questions.md](open-questions.md).

## Каналы
- **Клиентский веб-сайт.** См. [решение 0003](decisions/0003-core-and-channels.md).
- **Мини-приложение в боте.** Общий фронтенд с клиентским сайтом. См. [решение 0017](decisions/0017-bot-format.md).

## Бот
- **Переводы на другие языки** — по запросу сообщества. Механизм заложен с MVP ([решение 0018](decisions/0018-languages.md)).
- **Темы в личных чатах** — отдельная ветка «Поддержка» внутри бота (Bot API 9.3).
- **Расширение rich-сообщений** на другие экраны — если формат покажет себя хорошо.
- **Эффекты сообщений** (например, на успешную оплату) — «без фанатизма».
