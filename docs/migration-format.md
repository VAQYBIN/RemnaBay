# Промежуточный формат миграции

**Статус:** ✅ утверждён как контракт версии 1; поля уточняются при реализации адаптера — с повышением версии формата.

Публичный контракт между адаптерами чужих ботов и импортом магазина ([решение 0002](decisions/0002-migration-via-panel.md), критерии 9.8–9.17). Любой может написать адаптер для своего бота: достаточно выдать файл в этом формате.

## Общее
- Один файл JSON в кодировке UTF-8.
- Поле `format_version` — номер версии формата. Импорт отказывается принимать неизвестную версию и сообщает, какие поддерживает.
- Поле `source` — откуда данные: название бота и версия, если известна.
- Обязательные поля отмечены «да»; необязательные адаптер может опустить, если в источнике их нет.

## Клиент
| Поле | Обязательно | Значение |
|---|---|---|
| Telegram ID | да | Идентификатор клиента |
| username | нет | Без «@» |
| Имя | нет | Как в старом боте |
| Язык | нет | Код языка клиента |
| Дата появления | нет | Когда клиент впервые открыл старый бот |
| Триал использован | нет | Да или нет; если поле отсутствует — считается «нет» |
| Пользователи панели | нет | Список: числовой ID, короткий идентификатор (`shortUuid`) и/или имя (`username`) пользователя панели; хватает любого одного ([решение 0043](decisions/0043-panel-checks-refinements.md)) |
| Реферальные коды | нет | Коды старого бота, ведущие на этого клиента |
| Пригласивший | нет | Telegram ID клиента, который пригласил этого |

## Сопоставление тарифов (необязательно)
Если в старом боте есть тарифы, адаптер может передать подсказку: какой тариф старого бота был у пользователя панели. Импорт показывает подсказку в пробном прогоне; окончательное сопоставление с тарифами магазина задаёт оператор (9.15).

## Чего в формате нет и почему
- **Платежи старого бота** — магазин их не видел; стоимость перенесённых дней равна нулю ([решение 0012](decisions/0012-tariff-change.md)).
- **Балансы и бонусы** — бонусного счёта в MVP нет; оператор при желании начислит бонусы сам (v1).
- **Срок, трафик, устройства** — живут в панели и берутся оттуда.
