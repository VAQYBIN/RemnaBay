# Правила для ИИ-агентов

## Стадия проекта
Проект находится на стадии **проектирования функционала**. Код не пишется, стек не выбирается, структура приложения не закладывается — до тех пор, пока в `docs/06-scope.md` MVP не отмечен как утверждённый.

Если тебя просят написать код, а MVP не утверждён, — напомни об этом и спроси, точно ли это нужно сейчас.

## Источник истины
- Спецификация в `docs/` — единственный источник истины о том, что делает продукт.
- Продуктовые решения принимает только владелец проекта. Агент их не принимает.
- Если в спеке нет ответа на вопрос — **не выдумывай**. Добавь вопрос в `docs/open-questions.md` и задай его владельцу.
- Если твоё предложение ещё не утверждено, помечай его явно: `> **Предложение (не утверждено):** ...`

## Работа с документацией
- Слои спеки идут по порядку (см. `docs/README.md`). Не заполняй следующий слой, пока предыдущий не утверждён, — если только об этом не попросили.
- Каждое принятое решение, которое влияет на продукт, записывается в `docs/decisions/` по шаблону `docs/decisions/template.md`.
- Используй термины из `docs/glossary.md`. Новый термин — сначала в глоссарий.
- Язык документации — русский.
- Не удаляй и не переписывай утверждённые разделы без прямой просьбы.
